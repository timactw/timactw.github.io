隱私權政策

最後更新：2026-11-03

  1. 使用者範圍：本工具僅供開發者本人使用，只存取本人自己的 Google 帳號。
  2. 存取的資料：經本人授權後，存取本人的 Gmail、Google 日曆、雲端硬碟、文件、試算表、待辦事項與聯絡人。
  3. 用途：只用於本人的個人事務整理（整理信件、行程、待辦、上傳筆記）。
  4. 儲存：授權憑證以加密方式只存在本人的電腦上；不在任何伺服器上保存 Google 使用者資料。
  5. 分享：不出售、不分享、不轉移任何 Google 使用者資料給第三方，也不用於廣告。
  6. 撤銷：可隨時在 Google 帳戶權限頁 撤銷授權。
  7. 聯絡：透過本網站所屬的 GitHub 帳號 timactw 聯絡。

本工具使用 Google API 取得的資料，遵守 Google API Services User Data Policy，包含 Limited Use 規定。

Privacy Policy (English)

This tool is used solely by its developer to access the developer's own Google account. Google user data (Gmail, Calendar, Drive, Docs, Sheets, Tasks, Contacts) is used only for the developer's personal organization, credentials are stored encrypted on the developer's own computer, and no data is sold, shared, transferred to third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions. Contact: GitHub user timactw.
